# 💻 Estudos Frontend


Repositório com todas as atividades, exercícios e projetos desenvolvidos durante meus estudos de desenvolvimento frontend, feitos por conta própria fora do ambiente acadêmico. O repositório cresce conforme novas tecnologias e conceitos são aprendidos, sem data de término prevista.

---
## Sobre

Estudos estruturados seguindo um roadmap próprio de Front-end (HTML & CSS) — Do Zero ao Intermediário, cobrindo as principais tecnologias e conceitos do desenvolvimento front-end:

- HTML5 semântico e estruturado
- Formulários e validação nativa
- CSS3 (Box Model, seletores e cascata)
- Flexbox e CSS Grid
- Responsividade e Media Queries (Mobile-First)
- Transições e animações
- Arquitetura de classes de estado
